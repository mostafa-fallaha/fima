# FiMA session continuity

- Read `plan.md` at the start of a new session for project goals, accepted
  decisions, current implementation, working commands, known issues, and next steps.
- Inspect the current repository before acting; distinguish recorded history,
  proposals, and user-confirmed behavior from fresh verification.
- Build one component at a time and explain the work so the user can learn.
  Discuss the next component's small design before implementing it. Routine fixes
  within the current component and documentation updates can proceed normally.
- Keep the initial end-to-end workflow English-only and USD-only. All AI runs on
  the PC; the watch and phone capture, store, transfer, and display results.
- Favor simple solutions and make decisions when the current component needs them.
- Update `plan.md` after meaningful work, and README.md when setup or usage changes.
  Preserve private audio, credentials, and existing user changes.
- The user's latest instructions take precedence over this handoff.
